# WebGL React Components with AETumi

A collection direction and implementation reference for reusable **WebGL components in React and Next.js**.

AETumi is an AI-native 3D web platform for production-ready Three.js, WebGL, React and Next.js experiences, with reusable components, prompts and MCP workflows for AI coding assistants.

## Component ideas

- Animated WebGL backgrounds
- Shader-driven hero sections
- Particle systems
- Distortion and displacement effects
- Interactive gradients and noise
- Product reveal components
- Cursor-reactive effects
- Full-screen canvas sections

## Architecture goals

- Reusable React components
- Clean client/server boundaries in Next.js
- Responsive canvas sizing
- Reduced motion fallbacks
- Lazy loading for heavy scenes
- Clear teardown and resource disposal
- Performance budgets for production sites
